# 腾讯云函数 (SCF) 部署教程 — 新手向

> 你的实盘交易机器人从 GitHub Actions 搬到腾讯云函数上跑，彻底告别限流、永久免费。

---

## 📖 先搞懂几个概念（30 秒）

| 名词 | 大白话 |
|---|---|
| **SCF 云函数** | 腾讯云的"代码托管运行服务"。你上传一段 Python 代码，设置"每 15 分钟跑一次"，它就自动跑。不用管服务器、不用开机。 |
| **函数** | 就是你的一份代码 + 配置。相当于 GitHub 里的一个 workflow。 |
| **触发器** | 什么时候跑代码。我们用"定时触发器"，就像 cron。 |
| **环境变量** | 把 OKX 的密钥存在这里，不写死在代码里（安全）。 |
| **免费额度** | 每月 100 万次调用 + 40 万 GB-s 计算资源。你一天用不到 100 次，**完全免费**。 |

## 🚀 部署步骤（跟着点就行）

### 第 1 步：注册腾讯云（已有账号跳过）

1. 打开 https://cloud.tencent.com/
2. 右上角"注册"，用微信扫码最方便
3. 完成**实名认证**（必须，否则用不了云函数）

### 第 2 步：进入云函数控制台

1. 顶部搜索框搜"**云函数**"，点进去
2. 或者直接访问：https://console.cloud.tencent.com/scf
3. 第一次进会让你"开通服务"，点确认就行（免费的）

### 第 3 步：新建函数

1. 左侧菜单 → **函数服务**
2. 左上角选地域：选**广州**或**上海**（国内节点访问 OKX 快）
3. 点 **新建** → 选 **从头开始**
4. 填写基础信息：
   - **函数名称**：`okx_live_trade`（随便起，英文）
   - **运行环境**：选 **Python 3.9** 或 **Python 3.10**
   - **函数类型**：**事件函数**
   - **内存**：**128 MB**（够用了，省额度）
   - **超时时间**：**60 秒**（每次扫描 30 秒内搞定）
5. 点 **完成** / **下一步**

### 第 4 步：上传代码

进到函数详情页后，在 **函数代码** 选项卡：

**方式 A：直接在编辑器里粘贴（最简单）**

1. 把 `index.py` 的内容全部复制，粘贴到编辑器里（替换默认的 index.py）
2. 点编辑器上方的 **新建文件**，文件名填 `live_trader.py`，把 `live_trader.py` 的内容粘贴进去
3. 再新建文件 `requirements.txt`，粘贴内容
4. 点 **部署**

**方式 B：上传 ZIP 包（推荐，文件多的时候方便）**

1. 把本目录（`scf/`）里的 **3 个文件** 打包成 zip：
   - `index.py`
   - `live_trader.py`
   - `requirements.txt`
   > ⚠️ 注意：是把 3 个文件直接打包，不要带外层 `scf` 文件夹！
2. 函数代码页 → 右上角 **上传代码** → **本地上传 ZIP 包**
3. 选你打好的 zip，上传
4. 点 **部署**

### 第 5 步：安装依赖（重要！）

代码上传完了，但 `ccxt`、`pandas` 这些第三方库还没装。有两种方式：

**方式 A：在线安装依赖（推荐，最省事）**

1. 函数详情页 → **函数代码** → 找到 **终端 / 命令行** 入口（或者叫"在线终端"）
2. 在终端里执行：
   ```bash
   cd /tmp
   pip install -r /var/user/requirements.txt -t /var/user/
   ```
   > 不同版本控制台路径可能不一样，如果找不到终端，用方式 B。

**方式 B：本地打包依赖上传（稍微麻烦但稳）**

1. 在你自己电脑上，找个空文件夹
2. 把 3 个代码文件放进去
3. 在该目录下执行：
   ```bash
   pip install ccxt pandas numpy -t .
   ```
4. 把整个文件夹（包括安装好的库）打包成 zip
5. 上传这个大包

> 💡 提示：第一次部署完一定要先测试一次，看日志里有没有 `ModuleNotFoundError`，有的话就是依赖没装好。

### 第 6 步：配置环境变量（放 OKX 密钥）

1. 函数详情页 → **函数配置** → 点 **编辑**
2. 往下找到 **环境变量** 区域
3. 添加以下 3 个（必填）：

| 变量名 | 值 | 说明 |
|---|---|---|
| `OKX_LIVE_API_KEY` | 你的 OKX API Key | OKX 后台生成的 |
| `OKX_LIVE_API_SECRET` | 你的 OKX Secret | OKX 后台生成的 |
| `OKX_LIVE_PASSPHRASE` | 你的 OKX 资金密码 | 你自己设的 passphrase |

4. （可选）再加飞书通知：
   | 变量名 | 值 |
   |---|---|
   | `FEISHU_LIVE_WEBHOOK` | 飞书机器人 webhook 地址 |

5. 点 **保存**

> 🔐 安全提示：环境变量只有你能看到，比写在代码里安全得多。

### 第 7 步：测试运行一次

1. 回到 **函数代码** 页
2. 点 **测试** / **运行测试**
3. 看右侧 **执行结果** 和 **日志**
4. 正常的话应该看到：
   ```
   [SCF] 触发开始
   🔑 密钥已加载: API_KEY=xxx***
   ...（策略日志）...
   [SCF] 执行完成
   ```
5. 如果报错，把日志截图发给我，我帮你看。

### 第 8 步：设置定时触发器（让它自动跑）

1. 函数详情页 → **触发器管理** → **创建触发器**
2. 填写：
   - **触发方式**：**定时触发**
   - **触发器名称**：`every_15min`（随便起）
   - **触发周期**：选 **自定义触发周期**
   - **Cron 表达式**：填 `*/15 * * * *`（每 15 分钟一次）
     > 想改频率就改这个数字，比如 `*/30 * * * *` = 每 30 分钟
3. 点 **提交**

✅ 完成！从现在起，每 15 分钟它会自动跑一次。

## 📊 怎么看它有没有在跑

### 看运行记录
函数详情页 → **运行记录** / **监控信息**
- 能看到每次调用的时间、耗时、成功/失败
- 点进去能看详细日志

### 看日志
函数详情页 → **日志查询**
- 可以搜关键词，比如 `做多`、`做空`、`挂单`
- 报错信息也在这里

## ⚠️ 注意事项

1. **IP 白名单**：如果你 OKX API 设置了 IP 白名单，需要把腾讯云函数的出口 IP 加进去。
   - 腾讯云函数的出口 IP 不固定，建议**暂时关掉白名单**或者用"固定出口 IP"功能（需要单独配置）。

2. **免费额度够用吗？**
   - 每月 100 万次调用 → 你每天 96 次（15分钟一次×24小时），每月才 ~2900 次
   - 每月 40 万 GB-s → 每次 128MB 跑 30 秒 = 0.125GB × 30s = 3.75 GB-s，每月才 ~1100 GB-s
   - **连免费额度的 1% 都用不到**，放心用。

3. **和 GitHub Actions 同时跑？**
   - **不要！** 两个一起跑会重复下单、重复加仓，乱套。
   - SCF 部署成功、测试通过后，去 GitHub 把那个 workflow 停掉：
     - 仓库 → Actions → OKX 实盘交易 → 右上角 `...` → **Disable workflow**
